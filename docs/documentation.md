# Geometric Lib

## Общее описание

Библиотека из 4 файлов, содержащих функции для вычисления площади и периметра.

Поддерживаемые фигуры: круг, прямоугольник, квадрат, треугольник.

## Описание функций

### Круг

#### `area(r)`

Возвращает площадь круга

**Параметры:**
- `r` (int): десятичное число, радиус окружности
        
**Возвращаемое значение:**
- `π * r * r` (float): десятичное число, площадь окружности радиуса r

**Пример вызова:**
```python
print(area(1)) # = 3.141592653589793
```

#### `perimeter(r)`

Возвращает периметр окружности

**Параметры:**
- `r` (int): десятичное число, радиус окружности

**Возвращаемое значение:**
- `2 * π * r` (float): десятичное число, периметр окружности радиуса r

**Пример вызова:**
```python
print(perimeter(1)) # = 6.283185307179586
```

---

### Прямоугольник

#### `area(a, b)`

Возвращает площадь прямоугольника

**Параметры:**
- `a` (int): десятичное число, длина одной стороны прямоугольника
- `b` (int): десятичное число, длина другой стороны прямоугольника

**Возвращаемое значение:**
- `a * b` (int): десятичное число, площадь прямоугольника

**Пример вызова:**
```python
print(area(2, 2)) # = 4
```

#### `perimeter(a, b)`

Возвращает периметр прямоугольника

**Параметры:**
- `a` (int): десятичное число, длина одной стороны прямоугольника
- `b` (int): десятичное число, длина другой стороны прямоугольника

**Возвращаемое значение:**
- `2 * (a + b)` (int): десятичное число, периметр прямоугольника

**Пример вызова:**
```python
print(perimeter(1, 2)) # = 6
```

---

### Квадрат

#### `area(a)`

Возвращает площадь квадрата

**Параметры:**
- `a` (int): десятичное число, сторона квадрата

**Возвращаемое значение:**
- `a * a` (int): десятичное число, площадь квадрата

**Пример вызова:**
```python
print(area(3)) # = 9
```

#### `perimeter(a)`

Возвращает периметр квадрата

**Параметры:**
- `a` (int): десятичное число, сторона квадрата

**Возвращаемое значение:**
- `4 * a` (int): десятичное число, периметр квадрата

**Пример вызова:**
```python
print(perimeter(2)) # = 8
```

---

### Треугольник

#### `area(a, h)`

Возвращает площадь треугольника

**Параметры:**
- `a` (int): десятичное число, сторона треугольника
- `h` (int): десятичное число, высота треугольника, проведённая к данной стороне

**Возвращаемое значение:**
- `a * h / 2` (float): десятичное число, площадь треугольника

**Пример вызова:**
```python
print(area(2, 3)) # = 3
```

#### `perimeter(a, b, c)`

Возвращает периметр треугольника

**Параметры:**
- `a` (int): десятичное число, одна сторона треугольника
- `b` (int): десятичное число, вторая сторона треугольника
- `c` (int): десятичное число, третья сторона треугольника

**Возвращаемое значение:**
- `a + b + c` (int): десятичное число, периметр треугольника

**Пример вызова:**
```python
print(perimeter(1, 2, 3)) # = 6
```
